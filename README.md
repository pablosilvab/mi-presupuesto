# Mi Presupuesto

Personal cash-flow app. After salary hits the checking account and monthly bills are paid, how much liquid money is left?

The interface is in Spanish. Data stays in the browser (`localStorage`) for this origin, so each visitor has a private budget on their own device.

Built with AI assistance.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Backup

Use **Datos → Exportar / Importar** to download or restore a JSON backup. Clearing site data, switching browsers, or changing the site URL starts a separate budget.
